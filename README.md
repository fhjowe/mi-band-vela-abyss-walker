# 暗渊行者 · Abyss Walker

> 小米手环 10（Vela OS 快应用）· 肉鸽生存地牢走格子  
> 平台：Vela OS 快应用 ｜ 屏幕：212×520 胶囊屏 ｜ 包名：`com.anyuanxingzhe` ｜ 版本：1.0.0

一个黑暗奇幻风格的 **Roguelike 生存游戏**：你是一位被诅咒的探险者，被困在无限地牢「暗渊」中。每层由随机生成的房间与走廊组成，隐藏着怪物、宝藏、陷阱与未知事件。不断向下探索、收集装备、构建你的 Build，争取活着离开——或者，倒在下一层。

---

## ✨ 玩法亮点

- **走格子探索**：滑动操作角色移动，撞怪进战斗，触碰物品拾取
- **回合制战斗**：普攻 / 技能 / 药水 / 连击系统，节奏适配手环
- **肉鸽三选一**：升级时随机三选一强化，构筑你自己的 Build
- **装备系统**：35 种武器 / 32 种防具，含触发、叠层、代价与套装协同
- **状态与元素**：中毒、灼烧、冰冻、感电、流血——火毒爆炸、冰电麻痹
- **职业与转职**：战士 / 游侠 / 法师，8 级可转职
- **遗物 / 天赋 / 召唤**：27 遗物、34 天赋，史莱姆 / 影分身 / 喵星人召唤物挡刀
- **锻造与宝石**：商店可附魔武器、镶嵌宝石
- **技能书**：6 种可切换技能
- **每日任务与成就**：每日签到、每日任务、29 项成就
- **多模式**：无尽 / 挑战 / NG+ 轮回

## 🕹️ 操作说明

- **首页**：选择难度 / 职业 / 模式后开始冒险
- **地牢**：滑动屏幕移动角色，撞怪进战斗，触碰物品拾取
- **战斗**：点「攻击」普攻，点「技能」释放技能，点「药水」回血
- **商店**：购买强化、打造赌博、附魔镶嵌
- **背包**：查看装备属性、分解装备获得材料

## 🛠 构建与运行

前置：安装 [AIoT IDE](https://iot.mi.com/vela/quickapp/zh/guide/start/use-ide.html) 并按文档配置环境；首次执行 `npm install`。

```bash
# 调试构建
npm run build

# 正式发布（已签名 RPK）
npm run release

# 真机运行（热更新）
npm run start
```

产物：`dist/com.anyuanxingzhe.release.1.0.0.rpk`（约 60–70KB）。

> **真机安装**：可通过米坛社区 /「表盘自定义工具」→ 快应用安装，或使用 AIoT IDE 连接手环安装。  
> **签名**：`sign/` 内为开发证书。正式对外分发前，请用自有证书替换 `sign/private.pem` 与 `sign/certificate.pem`。
